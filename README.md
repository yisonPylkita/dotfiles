# dotfiles

My personal dotfiles. Run `bash new.bash` for a CLI/server setup, or `bash new.bash --gui` to also install Alacritty and the Nerd Font. Supports Ubuntu 22.04/24.04/26.04 LTS and macOS.

Machine-specific settings and secrets belong in `~/.zsh_local` (ignored by Git); start from `.zsh_local.example`. Codex's DeepSeek worker setup lives outside this repo in `~/.codex`.
